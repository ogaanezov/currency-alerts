# Выкладка в интернет

Адрес: https://currency-alerts.onrender.com

Сайт работает на Render (приложение из `Dockerfile`), база — PostgreSQL в Neon.
Оба сервиса бесплатные, банковская карта не нужна.

## Ограничения бесплатного тарифа

- Render усыпляет сайт, если 15 минут никто не заходит. Первое открытие после сна занимает
  около минуты. Пока сайт спит, курсы не собираются; при пробуждении приложение видит, что
  курсы старше часа, и сразу запрашивает новые.
- Память — 512 МБ. Java ограничена 75% (`-XX:MaxRAMPercentage=75` в `Dockerfile`),
  приложению хватает около 250 МБ.
- База Neon — 1 ГБ, этого хватит на годы почасовых курсов.

## 1. База в Neon

1. Зарегистрироваться на https://neon.com и создать проект (регион ближе к Европе).
2. На странице проекта нажать **Connect** и скопировать строку подключения. Из неё
   собрать `jdbc:postgresql://<host>/<database>?sslmode=require`: хост без `-pooler`
   (прямое подключение лучше подходит для миграций Flyway), имя и пароль — отдельно.

## 2. Сайт в Render

1. Зарегистрироваться на https://render.com через GitHub.
2. **New → Blueprint**, выбрать репозиторий `currency-alerts`. Render найдёт `render.yaml`.
3. Заполнить переменные (это секреты, их нет в репозитории):

   | Переменная | Что вписать |
   |---|---|
   | `SPRING_DATASOURCE_URL` | JDBC-строка из Neon, с `?sslmode=require` |
   | `SPRING_DATASOURCE_USERNAME` | пользователь из Neon |
   | `SPRING_DATASOURCE_PASSWORD` | пароль из Neon |
   | `OXR_APP_ID` | ключ Open Exchange Rates |
   | `ADMIN_TOKEN` | ключ владельца, любой длинный |

4. **Apply**. Первая сборка идёт несколько минут. Адрес сайта будет вида
   `https://currency-alerts-xxxx.onrender.com`.

Flyway при первом запуске сам создаст таблицы в базе Neon.

После каждого слияния в `main` Render сам пересобирает и перезапускает сайт.
