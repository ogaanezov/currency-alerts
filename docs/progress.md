## Принятые решения

- Первая версия: один пользователь, без регистрации, уведомления внутри приложения.
- Работает локально: пока компьютер выключен, курсы не собираются.
- Сбор курсов раз в час: максимум 744 запроса в месяц при лимите 1000.
- Курсы хранятся в `BigDecimal`, время в UTC.
- Уведомление только при пересечении порога, а не при каждой проверке.
- Ключ API только в переменной окружения `OXR_APP_ID`, никогда в git.
