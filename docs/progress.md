- Доменная модель в пакете `domain`: `Currency`, `CurrencyPair`, `ExchangeRate`,
  `Direction`, `AlertRule` (метод `isTriggeredBy`), `Notification`. Все record
  проверяют данные в конструкторе и бросают `IllegalArgumentException`.
- PostgreSQL 18 в Docker (`compose.yaml`), миграции Flyway: `V1` таблица `exchange_rates`,
  `V2` таблица `alert_rules`. Репозитории на `JdbcClient` в пакете `persistence`:
  `ExchangeRateRepository` (`save`, `findLatest`) и `AlertRuleRepository` (`save`, `findAll`).
  Тесты репозиториев идут на временной базе через Testcontainers.
- Клиент `OpenExchangeRatesClient` в пакете `rates` на `RestClient`: метод `fetchLatest`
  запрашивает `/latest.json` и возвращает список `ExchangeRate` с базой USD. Адрес, ключ
  (`OXR_APP_ID`) и таймауты (5 с соединение, 10 с ответ) в `application.properties`.
  Тесты на поддельном сервере `MockRestServiceServer`, без запросов в интернет.
- Сбор курсов в пакете `collection`: `RateCollectionService.collect(now)` пропускает запрос,
  если последний курс в базе моложе часа, иначе запрашивает и сохраняет курсы.
  `RateCollectionScheduler` вызывает его раз в `rates.collection.interval` (PT1H) и при ошибке
  пишет предупреждение в лог, не роняя приложение. `ExchangeRateRepository.save` возвращает
  `boolean` и пропускает дубли через `ON CONFLICT DO NOTHING`. Тест сервиса на Mockito.
  Проверено вживую: курсы EUR и GBP сохраняются, повторный старт не тратит лимит. Всего 31 тест.

## Принятые решения

- Первая версия: один пользователь, без регистрации, уведомления внутри приложения.
- Работает локально: пока компьютер выключен, курсы не собираются.
- Сбор курсов раз в час: максимум 744 запроса в месяц при лимите 1000.
- Курсы хранятся в `BigDecimal`, время в UTC.
- Уведомление только при пересечении порога, а не при каждой проверке.
- Ключ API только в переменной окружения `OXR_APP_ID`, никогда в git.
- `ExchangeRate` и `AlertRule` убирают лишние нули у `BigDecimal` (`stripTrailingZeros`),
  иначе значение из базы `0.90000000` не равно исходному `0.90`.
- Работа с базой через `JdbcClient` и обычный SQL, без JPA: так виден каждый запрос.
- В тестах сбор по расписанию выключен: `src/test/resources/config/application.properties`
  задаёт `rates.collection.enabled=false`, чтобы тесты не ходили во внешний API.
