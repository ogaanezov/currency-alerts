# Currency Alerts

Сервис для оповещений о курсах валют: собирает курсы из внешнего API и уведомляет,
когда курс пересекает заданный порог.

Проект в разработке. Сейчас готовы каркас приложения с проверочным адресом `/health`
и доменная модель. Подключена база PostgreSQL. Раз в час приложение само получает
курсы EUR, GBP, AMD и GEL к доллару из Open Exchange Rates, сохраняет их в базу и проверяет
правила оповещений: при пересечении порога создаётся уведомление, один раз на пересечение.
Правилами, курсами и уведомлениями можно пользоваться через веб-интерфейс или REST API.

## Что нужно для запуска

- Java 25. Проверить версию: `java -version`.
- Docker Desktop, запущенный. Проверить: `docker info`.
- Ключ Open Exchange Rates (App ID), бесплатный тариф: https://openexchangerates.org/signup.
  Без ключа приложение запускается, но курсы не собирает.

- Node.js 22 или новее — для интерфейса. Проверить: `node -v`.

Maven отдельно ставить не нужно: он запускается через `./mvnw`.

## Как запустить

Из корня проекта сначала запустить базу данных:

```bash
docker compose up -d
```

Затем ввести ключ. Он не отображается при вводе и не попадает в историю команд:

```bash
read -s "OXR_APP_ID?App ID: "
export OXR_APP_ID
```

Ключ живёт только в текущей вкладке терминала, поэтому приложение нужно запускать
в той же вкладке. Никогда не добавляйте ключ в файлы проекта.

Затем приложение:

```bash
./mvnw spring-boot:run
```

Приложение запустится на порту 8080. Проверить в другой вкладке терминала:

```bash
curl http://localhost:8080/health
```

Ожидаемый ответ:

```json
{"status":"UP"}
```

Остановить приложение: `Ctrl+C` в той вкладке, где оно запущено.
Остановить базу данных: `docker compose down`. Данные сохранятся до следующего запуска.

## Интерфейс

Интерфейс лежит в папке `ui` (TypeScript, Vite, Chart.js). Приложение должно быть запущено.
В другой вкладке терминала из корня проекта:

```bash
cd ui
npm install
npm run dev
```

`npm install` нужен только в первый раз. Затем открыть http://localhost:5173.
На странице текущие курсы, конвертер валют, график, правила (добавить и удалить) и уведомления. Данные обновляются раз в минуту.
Запросы `/api` Vite передаёт бэкенду на порт 8080.

## REST API

Полное описание с возможностью отправить запрос прямо из браузера:
http://localhost:8080/swagger-ui.html (приложение должно быть запущено).

| Запрос | Что делает |
|---|---|
| `GET /api/rules` | Все правила |
| `POST /api/rules` | Создать правило |
| `DELETE /api/rules/{id}` | Удалить правило и его уведомления |
| `GET /api/rates/{base}/{quote}?limit=24` | История курса, сначала новые |
| `GET /api/notifications` | Все уведомления, сначала новые |
| `GET /api/convert?from=EUR&to=GBP&amount=100` | Перевести сумму по последним курсам |

Пример: создать правило «сообщить, когда USD/EUR станет выше 0.95»:

```bash
curl -X POST http://localhost:8080/api/rules \
  -H 'Content-Type: application/json' \
  -d '{"base": "USD", "quote": "EUR", "direction": "ABOVE", "threshold": 0.95}'
```

Конвертер считает любую пару через доллар: например, EUR → GBP = (USD/GBP) / (USD/EUR).

При неверных данных API отвечает `400` и объясняет ошибку в поле `detail`.

## Как запустить тесты

```bash
./mvnw test
```

Для тестов нужен запущенный Docker: они сами поднимают отдельную временную базу
через Testcontainers. Тесты также запускаются в GitHub Actions при каждом push.
