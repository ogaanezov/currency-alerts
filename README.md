# Currency Alerts

Сервис для оповещений о курсах валют: собирает курсы из внешнего API и уведомляет,
когда курс пересекает заданный порог.

Проект в разработке. Сейчас готовы каркас приложения с проверочным адресом `/health`
и доменная модель: валюты, курсы, правила и уведомления. Подключена база PostgreSQL.
Сбор курсов и работающие оповещения появятся на следующих этапах, см. [план](PLAN.md).

## Что нужно для запуска

- Java 25. Проверить версию: `java -version`.
- Docker Desktop, запущенный. Проверить: `docker info`.

Maven отдельно ставить не нужно: он запускается через `./mvnw`.
API-ключ пока не нужен.

## Как запустить

Из корня проекта сначала запустить базу данных:

```bash
docker compose up -d
```

Затем приложение:

```bash
./mvnw spring-boot:run
```

Приложение запустится на порту 8080. Проверить в другой вкладке терминала:

```bash
curl http://localhost:8080/health
```

Ожидаемый ответ:

```json
{"status":"UP"}
```

Остановить приложение: `Ctrl+C` в той вкладке, где оно запущено.
Остановить базу данных: `docker compose down`. Данные сохранятся до следующего запуска.

## Как запустить тесты

```bash
./mvnw test
```

Для тестов нужен запущенный Docker: они сами поднимают отдельную временную базу
через Testcontainers. Тесты также запускаются в GitHub Actions при каждом push.
