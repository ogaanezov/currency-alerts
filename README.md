# Currency Alerts

Сервис для оповещений о курсах валют: собирает курсы из внешнего API и уведомляет,
когда курс пересекает заданный порог.

Проект в разработке. Сейчас готов каркас приложения с проверочным адресом `/health`.
Курсы и оповещения появятся на следующих этапах, см. [план](PLAN.md).

## Что нужно для запуска

- Java 25. Проверить версию: `java -version`.

Maven отдельно ставить не нужно: он запускается через `./mvnw`.
База данных и API-ключ пока не нужны.

## Как запустить

Из корня проекта:

```bash
./mvnw spring-boot:run
```

Приложение запустится на порту 8080. Проверить в другой вкладке терминала:

```bash
curl http://localhost:8080/health
```

Ожидаемый ответ:

```json
{"status":"UP"}
```

Остановить приложение: `Ctrl+C` в той вкладке, где оно запущено.

## Как запустить тесты

```bash
./mvnw test
```

Тесты также запускаются в GitHub Actions при каждом push.
