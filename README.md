# Currency Alerts

Сервис для оповещений о курсах валют: собирает курсы из внешнего API и уведомляет,
когда курс пересекает заданный порог.

Проект в разработке. Сейчас готовы каркас приложения с проверочным адресом `/health`
и доменная модель. Подключена база PostgreSQL. Раз в час приложение само получает
курсы EUR и GBP к доллару из Open Exchange Rates, сохраняет их в базу и проверяет
правила оповещений: при пересечении порога создаётся уведомление, один раз на пересечение.
Правила пока создаются через SQL, REST API и интерфейс появятся на следующих этапах,
см. [план](PLAN.md).

## Что нужно для запуска

- Java 25. Проверить версию: `java -version`.
- Docker Desktop, запущенный. Проверить: `docker info`.
- Ключ Open Exchange Rates (App ID), бесплатный тариф: https://openexchangerates.org/signup.
  Без ключа приложение запускается, но курсы не собирает.

Maven отдельно ставить не нужно: он запускается через `./mvnw`.

## Как запустить

Из корня проекта сначала запустить базу данных:

```bash
docker compose up -d
```

Затем ввести ключ. Он не отображается при вводе и не попадает в историю команд:

```bash
read -s "OXR_APP_ID?App ID: "
export OXR_APP_ID
```

Ключ живёт только в текущей вкладке терминала, поэтому приложение нужно запускать
в той же вкладке. Никогда не добавляйте ключ в файлы проекта.

Затем приложение:

```bash
./mvnw spring-boot:run
```

Приложение запустится на порту 8080. Проверить в другой вкладке терминала:

```bash
curl http://localhost:8080/health
```

Ожидаемый ответ:

```json
{"status":"UP"}
```

Остановить приложение: `Ctrl+C` в той вкладке, где оно запущено.
Остановить базу данных: `docker compose down`. Данные сохранятся до следующего запуска.

## Как запустить тесты

```bash
./mvnw test
```

Для тестов нужен запущенный Docker: они сами поднимают отдельную временную базу
через Testcontainers. Тесты также запускаются в GitHub Actions при каждом push.
